# References

Material this course draws on for ideas, ordering and worked examples. No text is copied; everything is rewritten around the ShopWave story. If you want to go deeper on any topic, start here.

## Free courses

- Google, *Machine Learning Crash Course*: https://developers.google.com/machine-learning/crash-course
- Kaggle Learn (Pandas, Intro to ML, Intermediate ML, Feature Engineering, Time Series, Deep Learning): https://www.kaggle.com/learn
- fast.ai, *Practical Deep Learning for Coders*: https://course.fast.ai
- Hugging Face, *NLP Course* and *LLM Course*: https://huggingface.co/learn
- Stanford CS229 lecture notes (for the maths behind Module 02–05): https://cs229.stanford.edu
- DeepLearning.AI short courses on prompting, RAG and agents: https://www.deeplearning.ai/short-courses

## Books

- Aurélien Géron, *Hands-On Machine Learning with Scikit-Learn, Keras and TensorFlow* (3rd ed.). The closest single book to this course.
- Andriy Burkov, *The Hundred-Page Machine Learning Book*.
- Christoph Molnar, *Interpretable Machine Learning* (free online): https://christophm.github.io/interpretable-ml-book
- Rob Hyndman and George Athanasopoulos, *Forecasting: Principles and Practice* (free online): https://otexts.com/fpp3
- Jay Alammar and Maarten Grootendorst, *Hands-On Large Language Models*.
- Chip Huyen, *Designing Machine Learning Systems*.

## Datasets

- Online Retail II, UCI Machine Learning Repository (Daqing Chen). CC BY 4.0. https://archive.ics.uci.edu/dataset/502/online+retail+ii. Used as the ShopWave transaction data.
- Titanic (Kaggle "Titanic: Machine Learning from Disaster"). https://www.kaggle.com/c/titanic
- Fashion-MNIST (Zalando Research), MIT licence. Loaded through Keras.
- IMDB reviews, loaded through Keras / Hugging Face datasets.
- Small synthetic tables in `data/` are generated by `data/make_small_tables.py` and are public domain.
