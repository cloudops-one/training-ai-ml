# Module 00 · The Big Picture

**ShopWave asks:** *"Everyone says we should use AI. Can it actually help us, and with what?"*

**Time:** about 4 hours. **Prerequisites:** Python basics.

## Where you are

It is your first week at ShopWave, an online store selling home and gift products to customers across Europe. The company has two years of orders in a spreadsheet, a support inbox nobody can keep up with, and a CEO who keeps reading about AI.

Before touching any data you need a map: what machine learning is, what it is not, which problems it fits, and what the work actually looks like from start to finish. That is this module.

## What you will be able to do afterwards

- Explain, in plain words, the difference between a program that follows rules and one that learns from data, and say when each is the right choice.
- Place AI, machine learning, deep learning and generative AI on one picture and know which ShopWave problems belong where.
- Tell supervised, unsupervised and reinforcement learning apart by asking one question: *do we have the answers already?*
- Describe the seven steps every ML project follows, and know which step usually goes wrong.
- Recognise every piece of the course, because you will have run a miniature version of all of it in one notebook.
