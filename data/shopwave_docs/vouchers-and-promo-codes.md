# Gift vouchers and promo codes

## Gift vouchers

- Gift vouchers are available from **£10 to £200**.
- They are valid for **24 months** from the date of purchase.
- Vouchers cannot be exchanged for cash and are not replaced if lost.
- You can use more than one gift voucher on a single order.

## Promo codes

- Only **one promo code** can be used per order.
- New customers get **10% off their first order over £25** with the code **WELCOME10**.
- Promo codes cannot be used on wholesale orders or to buy gift vouchers.
- A promo code cannot be added after an order has been placed.
