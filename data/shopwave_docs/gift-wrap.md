# Gift wrapping and gift messages

## Gift wrap

- Gift wrap costs **£3.50 per item**.
- We use recycled brown paper, a cotton ribbon and a paper tag. No plastic.
- Gift wrap is not available for items longer than **60 cm** or for wholesale orders.

## Gift messages

- Add a free handwritten message of up to **200 characters** at checkout.
- Gift orders include a **gift receipt** with no prices on it.

## Sending to someone else

You can send a gift directly to another address. The recipient can return it for a gift voucher using the order number on the gift receipt.
