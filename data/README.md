# Data

## Small tables (committed, used for by-hand work)

| File | Rows | Used in | Description |
|---|---|---|---|
| `shopwave_visits_spend_5.csv` | 5 | 02.2, 02.3, 02.4 | Website visits vs next-month spend. Numbers chosen so the arithmetic is clean. |
| `shopwave_customers_small.csv` | 20 | 02–04 | Twenty ShopWave customers with visits, items, recency, country, next-month spend (regression target) and churned (classification target). |

Both are generated by `make_small_tables.py` with a fixed seed, so re-running gives identical files.

### Data dictionary: `shopwave_customers_small.csv`

| Column | Type | Meaning |
|---|---|---|
| `customer_id` | text | C001 … C020 |
| `visits_last_month` | integer | website visits in the last 30 days |
| `items_last_month` | integer | items bought in the last 30 days |
| `days_since_last` | integer | days since the most recent order |
| `country` | category | UK, DE or FR |
| `spend_next_month` | number | what the customer spent in the following month (regression target) |
| `churned` | 0 / 1 | 1 if the customer placed no order in the next 90 days (classification target) |

## Real data (downloaded, git-ignored)

`python data/download.py` fetches **Online Retail II** (UCI, CC BY 4.0) into `data/raw/online_retail_II.xlsx`: about one million real transactions from a UK online retailer, December 2009 to December 2011. In the course this is ShopWave's transaction history.

| Column | Meaning |
|---|---|
| `Invoice` | invoice number; starts with `C` if the order was cancelled |
| `StockCode` | product code |
| `Description` | product name |
| `Quantity` | units ordered (negative for returns) |
| `InvoiceDate` | timestamp |
| `Price` | unit price in GBP |
| `Customer ID` | customer number (missing for guest checkouts) |
| `Country` | customer's country |

In notebooks, load it with:

```python
from download import load_retail
raw = load_retail()                    # "Year 2010-2011"; or load_retail("Year 2009-2010")
```

The first call reads the Excel file (10–60 s) and saves a Parquet copy in `data/raw/`; every later call takes about a second.

Other datasets (Titanic, Fashion-MNIST, IMDB reviews) are fetched by the notebooks that use them.
